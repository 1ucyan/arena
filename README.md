# Арена — спортивные турниры (версия для GitHub Pages)

Статический сайт для проведения турниров: жеребьёвка, сетки, таблицы, результаты, пьедестал и табло для телевизора или проектора. Сервер, сборка и установка программ не нужны: GitHub Pages просто раздаёт эти файлы.

## Что важно знать заранее

- **Турниры хранятся в браузере того, кто их создал.** У каждого посетителя сайта свой список турниров, остальные его не видят. Другой браузер, другое устройство или режим инкогнито покажут пустой список. Очистка данных браузера удаляет турниры. Поэтому время от времени сохраняйте копию: «Мои турниры» → «Резервная копия» → «Сохранить копию». Файл копии можно загрузить в другом браузере кнопкой «Загрузить копию».
- **Поэтому в этой версии нет ролей «Организатор» и «Зритель», публичной ссылки на турнир и QR-кода.** Без сервера показать турнир другим людям нельзя. Всё это есть в серверной версии, размещённой в Sites.
- **Табло работает на том же компьютере.** Откройте турнир, нажмите «Табло числовое» или «Табло сетка», перенесите окно на телевизор или проектор (второй экран) и нажмите «Во весь экран» или клавишу F. Когда вы вносите счёт в основном окне, табло обновляется само.

## Размещение через браузер

1. Войдите на [github.com](https://github.com) и нажмите **New** (новый репозиторий). Укажите имя, например `arena-turniry`, выберите **Public** и нажмите **Create repository**. На бесплатном тарифе GitHub Pages работает только с публичными репозиториями.
2. На странице пустого репозитория нажмите ссылку **uploading an existing file**.
3. Распакуйте архив и перетащите в окно браузера **всё содержимое** папки `arena-github-pages`: файлы и папку `assets`. Перетаскивайте содержимое, а не саму папку: `index.html` должен оказаться в корне репозитория. Нажмите **Commit changes**.
   - Скрытый файл `.nojekyll` можно не загружать, сайт работает и без него.
4. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Source: Deploy from a branch**, ветку **main** и папку **/ (root)**, затем нажмите **Save**.
5. Через 1–2 минуты обновите страницу **Settings → Pages**: вверху появится адрес сайта вида `https://<логин>.github.io/arena-turniry/`. Сайт открывается из любой сети, в том числе с телефона.

## Размещение через git

Создайте на GitHub пустой репозиторий (шаг 1 выше), затем выполните в распакованной папке `arena-github-pages` (`<логин>` замените на свой логин GitHub):

```bash
git init -b main
git add .
git commit -m "Арена: сайт для GitHub Pages"
git remote add origin https://github.com/<логин>/arena-turniry.git
git push -u origin main
```

При `push` GitHub попросит логин и вместо пароля токен доступа (Settings → Developer settings → Personal access tokens). После этого включите Pages, как в шаге 4.

## Обновление сайта

Загрузите новые версии файлов тем же способом: через **Add file → Upload files** или `git push`. Файлы с теми же именами заменятся. Турниры посетителей хранятся в их браузерах и при обновлении сайта не пропадают.

## Состав

| Файл | Назначение |
|---|---|
| `index.html` | страница сайта |
| `style.css` | оформление |
| `core.js` | общие помощники: безопасная разметка, окна, уведомления; здесь включается локальный режим |
| `app.js` | интерфейс: создание турнира, ввод результатов, «Мои турниры» |
| `engine.js` | правила форматов, жеребьёвка, таблицы, пьедестал |
| `board.js` | сетки и таблицы встреч |
| `tv.js` | табло для телевизора или проектора |
| `participants.js` | загрузка списка участников из TXT и CSV |
| `qr.js` | генератор QR-кодов (в этой версии не используется) |
| `favicon.svg` | значок вкладки |
| `assets/fonts/` | шрифты Unbounded и Golos Text, лицензия SIL OFL 1.1 в `LICENSE.txt` |
| `.nojekyll` | отключает обработку Jekyll на GitHub Pages (необязателен) |
