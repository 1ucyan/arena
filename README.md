# Арена — спортивные турниры

Статический сайт для проведения турниров: жеребьёвка, сетки, таблицы, результаты, пьедестал и табло для телевизора или проектора. Сервер, сборка и установка программ не нужны: GitHub Pages просто раздаёт эти файлы.

## Что важно знать заранее

- **Турниры хранятся в браузере того, кто их создал.** У каждого посетителя сайта свой список турниров, остальные его не видят. Другой браузер, другое устройство или режим инкогнито покажут пустой список. Очистка данных браузера удаляет турниры. Поэтому время от времени сохраняйте копию: «Мои турниры» → «Резервная копия» → «Сохранить копию». Файл копии можно загрузить в другом браузере кнопкой «Загрузить копию».
- **Поэтому в этой версии нет ролей «Организатор» и «Зритель», публичной ссылки на турнир и QR-кода.** Без сервера показать турнир другим людям нельзя. Всё это есть в серверной версии, размещённой в Sites.
- **Табло работает на том же компьютере.** Откройте турнир, нажмите «Табло числовое» или «Табло сетка», перенесите окно на телевизор или проектор (второй экран) и нажмите «Во весь экран» или клавишу F. Когда вы вносите счёт в основном окне, табло обновляется само.
